# การแปลงข้อความก่อนอ่าน

โมเดลอ่านภาษาไทยได้ดีอยู่แล้ว สิ่งที่มันอ่านไม่ได้คือ **อักขระที่ไม่เคยต้อง
ออกเสียง** — เครื่องหมาย ตัวเลขที่มี punctuation คำอังกฤษ

หน้านี้อธิบายว่าอะไรถูกแปลงบ้าง ทำไม และจะเพิ่มเองยังไง

> **นี่ไม่ใช่การเทรนโมเดล** F5-TTS เป็น zero-shot voice cloning — fine-tune
> ต้องใช้เสียงคู่ข้อความหลายชั่วโมง ไม่ใช่รายการคำ · การแปลงข้อความคือสิ่งที่
> แก้การออกเสียงได้จริงและทำได้ทันที

## สองชั้น

| ชั้น | ไฟล์ | ครอบคลุม |
|---|---|---|
| **กฎ** | `gpu-node/thai_normalize.py` | สิ่งที่เป็นระบบ — ตัวเลข เวลา วันที่ เบอร์โทร อีเมล markdown · ครอบคลุม**ทุกกรณี** ไม่ใช่เฉพาะที่ลิสต์ |
| **พจนานุกรม** | `gpu-node/thai_lexicon.yaml` | สิ่งที่ต้องบอกถึงจะรู้ — ตัวย่อ คำทับศัพท์ ศัพท์ไอที ชื่อผลิตภัณฑ์ · **~290 รายการ** และเพิ่มได้เรื่อย ๆ |

## สิ่งที่แปลงให้ทั้งหมด

ทุกแถวมาจากการอ่านผิดจริงที่วัดได้ (สังเคราะห์ → ถอดกลับด้วย Whisper → เทียบ)

### ตัวเลข

| ข้อความ | ก่อน | หลัง |
|---|---|---|
| `23:45 น.` | "สองพันสามร้อยสี่สิบห้า" | ยี่สิบสามนาฬิกาสี่สิบห้านาที |
| `36.5` | "สามร้อยหกสิบห้า" | สามสิบหกจุดห้า |
| `85%` | "แปดสิบห้า" | แปดสิบห้าเปอร์เซ็นต์ |
| `10/09/2026` | "สิบล้านเก้าพัน…" | วันที่สิบ กันยายน สองพันยี่สิบหก |
| `1,250 บาท` | ✓ | หนึ่งพันสองร้อยห้าสิบบาท |
| `พอร์ต 8766` | "แปดพันเจ็ดร้อยหกสิบหก" | แปดเจ็ดหกหก |
| `041` | "สี่สิบเอ็ด" | ศูนย์สี่หนึ่ง |
| `28-33 องศา` | "ยี่สิบแปด-สามสิบสาม" (ขีดเงียบ) | ยี่สิบแปด ถึง สามสิบสาม |
| `27 — 84` | ขีดยาวหายไป อ่านเป็นสองจำนวน | ยี่สิบเจ็ด ถึง แปดสิบสี่ |
| `2026-09-11` | "สองพันยี่สิบหก ศูนย์เก้า สิบเอ็ด" | วันที่สิบเอ็ด กันยายน สองพันยี่สิบหก |

**จำนวน vs รหัส** — `1,250 บาท` เป็นจำนวน แต่ `พอร์ต 8766` เป็นรหัส · คำที่ทำให้
อ่านทีละตัว: พอร์ต, port, รหัส, เบอร์, หมายเลข, ห้อง, version (เพิ่มได้ที่
`_DIGITWISE_AFTER`) · เลขติดกัน 7 ตัวขึ้นไปถือเป็นรหัสเสมอ

**เลขที่ขึ้นต้นด้วยศูนย์เป็นรหัสเสมอ** ไม่ต้องมีคำนำหน้า — อ่าน `041` เป็น
"สี่สิบเอ็ด" ทำให้ศูนย์หายไปทั้งตัว กลายเป็น*คนละเลข* ไม่ใช่แค่ออกเสียงเพี้ยน ·
`0.1` ยังเป็นจำนวน (มีจุดทศนิยม) และ `0` เดี่ยว ๆ ก็ยังเป็นจำนวน

**ช่วงตัวเลข** — `28-33`, `27 — 84`, `2020-2024` → คั่นด้วย "ถึง" · กฎนี้ทำงาน
*หลัง* เบอร์โทร IP และวันที่ ซึ่งกินขีดของตัวเองไปแล้ว · `2026-09-11` ไม่โดน
เพราะตัวเลขที่ตามมาปิดกั้นไว้

### ช่องว่าง — จุดที่ทำให้ "พูดแปลก" มากที่สุด

**ภาษาไทยไม่เว้นวรรคระหว่างคำ ช่องว่างคือการแบ่งวรรค ซึ่งอ่านออกเสียงเป็น "การหยุด"**

เครื่องหมายเน้นข้อความต้องมีที่ว่างรอบตัว คนเขียนจึงพิมพ์ `ผม "นึก" ว่า` ·
ถ้าตัดแค่เครื่องหมายจะเหลือ `ผม นึก ว่า` — **หยุดขนาบคำที่ถูกเน้นทั้งสองข้าง**

ระบบจึงตัดเครื่องหมาย**พร้อมช่องว่างที่มันต้องการ**ไปด้วย → `ผมนึกว่า`

> **เชื่อมเฉพาะช่วงสั้น (≤12 อักษรไทย)** เท่านั้น · ความพยายามครั้งแรกเชื่อมทุกจุด
> แล้วไปรวมประโยคติดกัน (`เกินเหตุ **เอาล่ะครับ` → `เกินเหตุเอาล่ะครับ`) เพราะ
> เครื่องหมายที่เปิดประโยคใหม่**หน้าตาเหมือน**เครื่องหมายที่ครอบคำเป๊ะ ๆ ·
> ความยาวคือตัวแยกที่ใช้ได้จริง

> **และเครื่องหมายสองฝั่งต้องเป็นชนิดเดียวกัน** · `**` ปิดด้วย `"` ไม่ใช่การครอบคำ
> แต่คือ*ท้ายประโยคหนึ่งมาเจอหัวอีกประโยคหนึ่ง* — `...นะครับ 😉 **ถ้าจะให้ผม "จัดเต็ม"`
> ถูกรวบเป็น `นะครับถ้าจะให้ผม` ทำให้เส้นแบ่งประโยคหายไปเลย · `**"คำ"**` ยังเชื่อม
> ตามปกติ เพราะทั้งสองฝั่งประกอบด้วยเครื่องหมายชุดเดียวกัน

เก็บช่องว่างค้างหน้า `, ; ? !` ด้วย — ตัดเครื่องหมายแล้วมักเหลือช่องว่างไว้

### วงเล็บอังกฤษที่ซ้ำกับไทย

การเขียนแบบไทยชอบใส่คำอ่านอังกฤษในวงเล็บให้คนอ่านสายตา:

```
ด้านฟีเจอร์และประสิทธิภาพ (Features & Performance)
```

อ่านออกเสียงแล้ว**พูดเรื่องเดียวกันสองภาษา** และทำให้คำตอบยาวขึ้นเท่าตัว ·
ระบบจึงตัดวงเล็บที่มีแต่อักษรละตินและตามหลังข้อความไทยทิ้ง

| กรณี | ผล |
|---|---|
| `ความคุ้มค่า (Cost & Licensing)` | ตัดทิ้ง — ไทยข้าง ๆ บอกความหมายแล้ว |
| `เริ่มงานใหม่ (เช่น เขียนโค้ด)` | **เก็บไว้** — เป็นเนื้อหา ไม่ใช่คำอ่าน |
| `HA (High Availability)` | **เก็บไว้** — อธิบายตัวย่อ ไม่ได้พูดซ้ำ |

วิธีนี้ได้ผลกว่าการเพิ่มพจนานุกรม เพราะวงเล็บอังกฤษเป็น**นิสัยการเขียน** จึงมาพร้อม
ศัพท์ใหม่ที่พจนานุกรมยังไม่มีเสมอ — และตัดทิ้งยังทำให้คำตอบสั้นลงด้วย

### Markdown และเครื่องหมาย

agent พิมพ์ markdown ออกมาเสมอไม่ว่าจะสั่งห้ามยังไง จึงตัดให้ที่นี่แทนที่จะ
ไปหวังพึ่ง prompt

| ข้อความ | ผล |
|---|---|
| `**ตัวหนา**` `*bullet*` `` `code` `` | ตัดเครื่องหมายทิ้ง |
| `### หัวข้อ` | ตัด `#` |
| `[ชื่อ]` + `(url)` แบบลิงก์ | เหลือแค่ชื่อ |
| `---` | ตัดทิ้ง |
| `"..."` | ตัดทิ้ง |
| `:` `(` `)` `[` `]` | กลายเป็นช่องว่าง |

**`1.` ที่ขึ้นต้นข้อ → "ข้อหนึ่ง"** — นี่คือบั๊กที่หนักที่สุดที่เจอ ถ้าปล่อยไว้
มันกลายเป็น `"หนึ่ง."` แล้ว**จุดนั้นคือ sentence terminator** ตัวแบ่งประโยคจึงตัด
ตรงนั้น ทำให้เสียงหยุดสนิททุกครั้งที่เจอเลขข้อ · จับเฉพาะเลขที่ตามด้วยจุดและ
เว้นวรรค ที่ต้นบรรทัดหรือหลังช่องว่าง เพื่อไม่ให้ไปโดน `36.5`

### คำอังกฤษ

| ข้อความ | ผล | เหตุผล |
|---|---|---|
| `CYN` `PDPA` `ID` | ซีวายเอ็น พีดีพีเอ ไอดี | ตัวพิมพ์ใหญ่ติดกันคือตัวย่อ สะกดทีละตัว |
| `v9` `v2.1` | เวอร์ชันเก้า · เวอร์ชันสองจุดหนึ่ง | เป็น**กฎ** ไม่ใช่พจนานุกรม เพราะเวอร์ชันมีไม่จำกัด · ต้องมีตัวเลขตาม ไม่งั้น `vSphere` จะโดนด้วย |
| `เวอร์ชัน v2.1` | เวอร์ชันสองจุดหนึ่ง | ไม่พูด "เวอร์ชัน" ซ้ำ |
| `GPU` | จีพียู | อยู่ในพจนานุกรมแล้ว ใช้ค่านั้น |
| `Data Subject` | ดาต้า ซับเจกต์ | จับวลียาวก่อนคำเดี่ยว |
| `cyngroup` | ซีวายเอ็นกรุ๊ป | แยกเป็น `cyn` + `group` |
| `Nero` | `Nero` | ยาวเกิน 4 ตัว ปล่อยให้โมเดลเดา |
| `cat` | `cat` | ตัวพิมพ์เล็กไม่ใช่ตัวย่อ |

**เกณฑ์ 4 ตัวอักษร** — คำไม่รู้จักที่สั้นกว่านี้คือตัวย่อ สะกดได้ · ยาวกว่านี้
ปล่อยให้โมเดลเดา เพราะ `example` สะกดเป็น "อีเอ็กซ์เอเอ็มพีแอลอี" ฟังแย่กว่า
เดาคำหยาบ ๆ

**แยกคำประสมแบบ backtracking** ไม่ใช่ greedy — greedy จะตัด `sales` ออกจาก
`salesupport` แล้วเหลือ `upport` ที่ไม่มีในพจนานุกรม ทั้งที่ `sale` + `support`
ครอบคลุมพอดี

### วลีซ้ำ

คนไทยชอบเขียนชื่ออังกฤษแล้ววงเล็บคำอ่านไทย พอแปลงเป็นไทยทั้งคู่จึงกลายเป็น
พูดซ้ำ:

```
CYN Communication (ซีวายเอ็น คอมมิวนิเคชั่น) จำกัด
  → บริษัท ซีวายเอ็น คอมมิวนิเคชั่น จำกัด        ← พูดครั้งเดียว
```

ยุบวลีซ้ำที่ติดกันได้ถึง 4 คำ · ยาวกว่านั้นมักตั้งใจ

## แก้ที่ต้นทางด้วย

พจนานุกรมจะแพ้เสมอถ้าไล่แปลงอย่างเดียว — คำตอบถัดไปก็หยิบศัพท์ใหม่มาอีก

`hermes.instructions` ใน `server.yaml` จึงสั่งให้ agent **เขียนคำอ่านไทยตั้งแต่แรก**:

```yaml
เขียนเป็นภาษาไทยให้มากที่สุด ศัพท์เทคนิคภาษาอังกฤษให้เขียนเป็นคำอ่านไทย
เช่น "เวอร์ชวลไลเซชัน" ไม่ใช่ "Virtualization" — เพราะคำตอบถูกอ่านออกเสียง
ไม่ได้อ่านด้วยตา
```

**การไม่เขียนอังกฤษตั้งแต่แรกคือทางเดียวที่ scale ได้** — normalizer เป็นตาข่ายรอง

## ลำดับสำคัญกว่าที่คิด

ความถูกต้องส่วนใหญ่มาจากลำดับ ไม่ใช่ตัว pattern:

| ต้องมาก่อน | ไม่งั้น |
|---|---|
| markdown → ทุกอย่าง | เครื่องหมายเข้าไปปนกับ pattern อื่น |
| อีเมล → สัญลักษณ์ `@` | ที่อยู่อีเมลถูกฉีกเป็นชิ้น |
| อีเมล → `@handle` | `user@host` ถูกจับเป็น handle |
| เบอร์โทร → ตัวเลขทั่วไป | แต่ละท่อนกลายเป็นจำนวน |
| วันที่ → เวลา | ทั้งคู่แย่งกลุ่มตัวเลขเดียวกัน |
| เวลา → ตัวย่อ | `น.` ขยายเป็น "นาฬิกา" ซ้ำ อ่านเวลาสองรอบ |
| เปอร์เซ็นต์ → ตัวเลข | `%` ถูกทิ้งไว้โดด ๆ |
| พจนานุกรม → ตัวย่อ | `GPU` ถูกสะกดทีละตัวแทนที่จะใช้ค่าที่ตั้งไว้ |
| เบอร์โทร/IP/วันที่ → ช่วงตัวเลข | `02-437-1210` ถูกอ่านเป็น "ศูนย์สอง ถึง …" |

**กรณีที่เคยพลาด:** ตอนสั่งตัด `:` ทิ้ง (เพราะ `**เบอร์โทรศัพท์:**`) มันไป
ทำลาย `23:45` ก่อนที่ `_times` จะทำงาน · แก้เป็นตัด `:` **ยกเว้นที่อยู่ระหว่าง
ตัวเลข** — เทสต์ที่มีอยู่จับ regression นี้ได้ทันที

## เพิ่มคำเอง

```yaml
# gpu-node/thai_lexicon.yaml
words:
  kubernetes: "คูเบอร์เนติส"
```

ไม่แน่ใจว่าสะกดยังไงดี ให้เครื่องช่วยเลือก:

```bash
python scripts/tune-lexicon.py docker ด็อกเกอร์ ดอกเกอร์ ด๊อกเก้อ --keep /tmp/clips
```

สังเคราะห์ทุกตัวเลือกแล้วส่งกลับให้ STT ถอด · ตัวอย่างจริง:

```
ด็อกเกอร์   → ตะเกียว      ✗
ดอกเกอร์    → ดอกเกลียด    ✗
ด๊อกเก้อ    → ดอกเกอร์     ✓  ← เลือกตัวนี้
```

> **อ่านเป็นการจัดอันดับ ไม่ใช่คำตัดสิน** — Whisper เองก็ไม่มีคำทับศัพท์อังกฤษ
> ส่วนใหญ่ในคลังภาษาไทย ถ้าคะแนนใกล้กันให้ฟังจาก `--keep` แล้วตัดสินด้วยหู

## ตรวจว่าโมเดลได้รับอะไร

```bash
curl -s -X POST http://<node>:8769/normalize \
  -H "X-Jarvis-Token: $JARVIS_TTS_TOKEN" -H 'Content-Type: application/json' \
  -d '{"text":"ตอนนี้เวลา 23:45 น."}'
```

```json
{"text": "ตอนนี้เวลา 23:45 น.", "normalized": "ตอนนี้เวลา ยี่สิบสามนาฬิกาสี่สิบห้านาที", "enabled": true}
```

## ปิดการแปลง

```bash
JARVIS_TTS_NORMALIZE_TEXT=0     # ทั้งระบบ
```

หรือรายคำขอ: `{"text": "...", "normalize": false}`
